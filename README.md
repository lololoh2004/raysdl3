# RayLib on SDL3 GPU
###### ( I call it rSDL or RaySDL )

### What is this ??
My attempt to rewrite **raylib from scratch** using SDL3 GPU.
It’s unlikely to go very far, though, since it’s just a **"can I do it?"** experiment.

The primary reason for creating it is to provide a **rendering backend for my engine** that is just as easy to use as raylib.

I plan to use **[SDL shadercross](https://github.com/libsdl-org/SDL_shadercross)** <img src="https://avatars.githubusercontent.com/u/77683370?s=60&v=4" width="15" style="vertical-align: middle;"> and **[cGLM](https://github.com/recp/cglm)** <img src="https://avatars.githubusercontent.com/u/1264894?s=60&v=4" width="15" style="vertical-align: middle;">
